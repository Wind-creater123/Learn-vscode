# ***初识http***

## **思考问题**

1. **http与https**

   - http超文本传输协议，规定浏览器与服务器之间数据传输的规则，格式。<u>未加密。</u>
   - https超文本传输==安全==协议，在http协议的基础上改进。<u>加密传输。</u>
   - http内容任何人可见，https的内容只有双方可见
   - 带小锁：使用https协议，加密，隐私性好，安全网站。

2. **协议**

- 协议是<u>*计算机之间传输数据预先定好的规则*</u>，使得不同系统间相互理解，从而通信
- 没有协议，前后端之间没有统一的格式，语言不同，无法相互理解

3. **协议之间的关系**

   1. http是面向连接的，故是==基于TCP（传输控制协议）的==
   2. UDP与TCP同为传输层协议

   - 但UDP不面向连接，故传输不可靠，但迅速
   - TCP稳定，数据完整，较慢（保证连接）

   1. websocket与http同一类型，解决了http的某些问题。

   - http是无状态协议，无记忆能力
     - 多次请求间记忆不共享
     - 每次请求独立
   - 在双方之间建立持久联系，双方均可传输数据

   1. IP协议为网络协议，在全球寻址

4. 状态码
    1. ==1xx响应中==
    2. ==2xx成功==
        - ==200-OK==
    3. ==3xx重定向==
        - 302-Found自动重新访问
        - 304-Not Modified使用本地缓存
    4. ==4xx客户端==错误
        - 400-Bad Request客户端语法错误，服务端不理解
        - 403-Forbidden拒绝提供服务，<u>无权限</u>
        - ==404-Not Found请求资源不存在==
        - 405-Method Not Allowed请求方式有误：请求资源用get，错用为post
        - 428-Precomdition Required需要携带特定的请求头
        - 429-Too Many Requests发送太多请求
        - 431-Request Header Fields Too Large请求头太大，服务器不处理
    5. ==5xx服务端==错误
        - ==500-Interanl Server Error服务器错误==
        - 503-Service Unavailable服务器未启动

5. 风险：隐私被他人非法获取，个人信息被盗
https加密传输数据，无法被破解

## **题目任务**

1. 协议理解

- 协议相当于翻译器，但翻译成双方都懂的一种语言
- 没有协议，前后端语言不通，协议分为4层<u>应用层->传输层->网络层->网络接口层</u>，提高效率，网络层寻找地址确定目标，传输层准确传输

2. *http协议分析*

- http定规则，统一数据格式
- 工作方式
  - http基于TCP向服务器发送连接请求
  - 浏览器发送请求（请求行，请求头，请求体）
  - 服务器处理后返回响应（响应行，响应头，响应体）
  - 关闭连接

3. http与http对比
    1. - http明文传输，无加密，任何人都可以看见传输内容
       -  https加密传输 
    2. TLS协议安全加密传输，网站需SSL协议验明身份，加密后难以破解，插入恶意代码，广告

4. 状态码见上

5. 非http协议

- 电子邮件使用SMTP,POP3协议，分别发送，接收邮件，同http基于TCP连接，但通信模式不同，http为（请求-响应），电子邮件为（存储转发）
