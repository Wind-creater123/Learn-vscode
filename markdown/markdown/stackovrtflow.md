   - 链接:
    <https://stackoverflow.com/questions/12335784/c-integer-overflow?rq=3>
   - 讨论要点:
     1. 楼主试验两个正数相加如果发生整型溢出,总是得到负数.
     负数相加发生overflow则得到正数,并询问是否普遍适用.
     2. 评论指出执行溢出对于有符号整型未定义,但对于unsigned整型有明确定义,如果楼主实验的数为有符号整型,什么都有可能发生
     3. 回答一表示:涉及整数的表达式在通常的算术转换后的结果是有符号类型的并且无法在结果中表示，则会溢出,赋值和强制转换是一个例外.并提醒不要让任何整数表达式溢出
     4. 回答二:有符号算术在溢出时的行为是未定义的;任何事情都有可能发生，这十分正常。这与无符号算术形成鲜明对比，无符号算术完全定义了溢出。
     5. 回答三:有符号整数的溢出在 C 中是未定义的行为，因此无法保证结果
   - ==总结:回答认为楼主实验时发生整型提升,使用的是unsigned整型所以结果有迹可循,认为他应该测试signed整型.因为unsigned整型在c中有定义,signed则没有==
